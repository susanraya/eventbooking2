# eventbooking2

basic event booking qpp

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Angular 22 app (Vite, Analog). Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a Spring Boot service (Java 21, Maven). No architecture had been
  approved when this repository was created, so it starts with its health check
  and nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
sh mvnw spring-boot:run
sh mvnw test
sh mvnw checkstyle:check spotless:check
sh mvnw spotless:apply
```
